     1→     1→# JKR International — Medical Equipment E-Commerce Platform
     2→     2→## Full Site Specification & Wireframe Blueprint for AI Build
     3→     3→
     4→     4→> **Reference Site:** https://web-production-5e010.up.railway.app/
     5→     5→> **Business:** Premium medical equipment supplier — UAE-based (Dubai & Abu Dhabi)
     6→     6→> **Model:** Enquiry-cart + direct purchase hybrid (B2B/B2C)
     7→     7→> **Currency:** AED | **Languages:** English + Arabic (RTL support required)
     8→     8→

    10→    10→
    11→    11→## 1. TECH STACK RECOMMENDATION
    12→    12→
    13→    13→```
    14→    14→Frontend:   Next.js 14 (App Router) + TypeScript + Tailwind CSS
    15→    15→Backend:    Django REST Framework (or Next.js API Routes if keeping JS-only)
    16→    16→Database:   PostgreSQL (products, users, orders, blog, enquiries)
    17→    17→Auth:       JWT + Django-allauth (or NextAuth.js)
    18→    18→Media:      Cloudinary (image CDN — already in use on reference site)
    19→    19→Search:     Algolia or Django Haystack (full-text product search)
    20→    20→Payments:   Tabby + Tamara + Network International + Cash on Delivery
    21→    21→Hosting:    Railway / Render / Vercel (frontend) + Railway (backend)
    22→    22→Admin:      Django Admin (customized) OR custom React admin panel
    23→    23→Email:      Resend / SendGrid (transactional: order confirm, newsletters)
    24→    24→```

    76→    76→## 3. DATABASE SCHEMA

    78→    78→### Products
    79→    79→```sql
    80→    80→Product {
    81→    81→  id, slug, name, name_ar,
    82→    82→  description, description_ar,
    83→    83→  short_description,
    84→    84→  sku, barcode,
    85→    85→  regular_price (AED), sale_price (AED),
    86→    86→  on_sale (bool), discount_percent (auto-calc),
    87→    87→  stock_qty, in_stock (bool),
    88→    88→  category_id (FK), subcategory_id (FK),
    89→    89→  brand_id (FK),
    90→    90→  is_featured, is_exclusive,
    91→    91→  meta_title, meta_description, meta_keywords,
    92→    92→  created_at, updated_at
    93→    93→}
    94→    94→
    95→    95→ProductImage {
    96→    96→  id, product_id (FK), image_url (Cloudinary),
    97→    97→  alt_text, sort_order, is_primary
    98→    98→}
    99→    99→
   100→   100→ProductReview {
   101→   101→  id, product_id (FK), user_id (FK),
   102→   102→  rating (1–5), review_text, is_approved, created_at
   103→   103→}
   104→   104→```
   105→   105→
   106→   106→### Taxonomy
   107→   107→```sql
   108→   108→Category {

   112→   112→}
   113→   113→
   114→   114→Brand {
   115→   115→  id, slug, name, logo_url, description, is_active

   120→   120→  banner_image_url, is_active, sort_order
   121→   121→}
   122→   122→
   123→   123→CollectionProduct { collection_id (FK), product_id (FK), sort_order }
   124→   124→```

   126→   126→### Users & Accounts

   128→   128→User {

   132→   132→}
   133→   133→
   134→   134→Address {

   139→   139→
   140→   140→### Orders & Enquiries
   141→   141→```sql
   142→   142→EnquiryCart {

   148→   148→  id, cart_id (FK), product_id (FK), quantity, notes
   149→   149→}
   150→   150→
   151→   151→Order {
   152→   152→  id, order_number, user_id (FK),
   153→   153→  billing_address (JSON), shipping_address (JSON),
   154→   154→  items (JSON snapshot), subtotal, discount, total,
   155→   155→  payment_method (tabby|tamara|network|cod),
   156→   156→  payment_status, order_status,
   157→   157→  notes, created_at, updated_at
   158→   158→}
   159→   159→
   160→   160→OrderItem {
   161→   161→  id, order_id (FK), product_id (FK),
   162→   162→  product_name, sku, unit_price, qty, subtotal
   163→   163→}
   164→   164→```
