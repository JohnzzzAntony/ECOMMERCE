     1→# JKR International — Medical Equipment E-Commerce Platform
     2→## Full Site Specification & Wireframe Blueprint for AI Build
     3→
     4→> **Reference Site:** https://web-production-5e010.up.railway.app/
     5→> **Business:** Premium medical equipment supplier — UAE-based (Dubai & Abu Dhabi)
     6→> **Model:** Enquiry-cart + direct purchase hybrid (B2B/B2C)
     7→> **Currency:** AED | **Languages:** English + Arabic (RTL support required)
     8→
     9→---
    10→
    11→## 1. TECH STACK RECOMMENDATION
    12→
    13→```
    14→Frontend:   Next.js 14 (App Router) + TypeScript + Tailwind CSS
    15→Backend:    Django REST Framework (or Next.js API Routes if keeping JS-only)
    16→Database:   PostgreSQL (products, users, orders, blog, enquiries)
    17→Auth:       JWT + Django-allauth (or NextAuth.js)
    18→Media:      Cloudinary (image CDN — already in use on reference site)
    19→Search:     Algolia or Django Haystack (full-text product search)
    20→Payments:   Tabby + Tamara + Network International + Cash on Delivery
    21→Hosting:    Railway / Render / Vercel (frontend) + Railway (backend)
    22→Admin:      Django Admin (customized) OR custom React admin panel
    23→Email:      Resend / SendGrid (transactional: order confirm, newsletters)
    24→```

    76→## 3. DATABASE SCHEMA
    77→
    78→### Products
    79→```sql
    80→Product {
    81→  id, slug, name, name_ar,
    82→  description, description_ar,
    83→  short_description,
    84→  sku, barcode,
    85→  regular_price (AED), sale_price (AED),
    86→  on_sale (bool), discount_percent (auto-calc),
    87→  stock_qty, in_stock (bool),
    88→  category_id (FK), subcategory_id (FK),
    89→  brand_id (FK),
    90→  is_featured, is_exclusive,
    91→  meta_title, meta_description, meta_keywords,
    92→  created_at, updated_at
    93→}
    94→
    95→ProductImage {
    96→  id, product_id (FK), image_url (Cloudinary),
    97→  alt_text, sort_order, is_primary
    98→}
    99→
   100→ProductReview {
   101→  id, product_id (FK), user_id (FK),
   102→  rating (1–5), review_text, is_approved, created_at
   103→}
   104→```
   105→
   106→### Taxonomy
   107→```sql
   108→Category {
   109→  id, slug, name, name_ar, image_url,
   110→  parent_id (FK, nullable → subcategory),
   111→  sort_order, is_active
   112→}
   113→
   114→Brand {
   115→  id, slug, name, logo_url, description, is_active
   116→}
   117→
   118→Collection {
   119→  id, slug, name, name_ar,
   120→  banner_image_url, is_active, sort_order
   121→}
   122→
   123→CollectionProduct { collection_id (FK), product_id (FK), sort_order }
   124→```
   125→
   126→### Users & Accounts
   127→```sql
   128→User {
   129→  id, email, phone, first_name, last_name,
   130→  role (customer | admin | staff),
   131→  is_active, date_joined
   132→}
   133→
   134→Address {
   135→  id, user_id (FK), label, line1, line2,
   136→  city, emirate, country, is_default
   137→}
   138→```
   139→
   140→### Orders & Enquiries
   141→```sql
   142→EnquiryCart {
   143→  id, session_key (for guests), user_id (FK nullable),
   144→  created_at
   145→}
   146→
   147→EnquiryCartItem {
   148→  id, cart_id (FK), product_id (FK), quantity, notes
   149→}
   150→
   151→Order {
   152→  id, order_number, user_id (FK),
   153→  billing_address (JSON), shipping_address (JSON),
   154→  items (JSON snapshot), subtotal, discount, total,
   155→  payment_method (tabby|tamara|network|cod),
   156→  payment_status, order_status,
   157→  notes, created_at, updated_at
   158→}
   159→
   160→OrderItem {
   161→  id, order_id (FK), product_id (FK),
   162→  product_name, sku, unit_price, qty, subtotal
   163→}
   164→```
   165→
   166→### Content
   167→```sql
   168→BlogPost {
   169→  id, slug, title, title_ar,
   170→  excerpt, content (rich text), author_id (FK),
   171→  cover_image_url, is_published, published_at,
   172→  meta_title, meta_description
   173→}
   174→
   175→Testimonial {
   176→  id, name, role, avatar_url, content, rating,
   177→  is_active, sort_order
   178→}
   179→
   180→ClientLogo { id, name, logo_url, website_url, sort_order, is_active }
   181→
   182→HeroSlide {
   183→  id, image_url, title, subtitle, cta_label, cta_url,
   184→  sort_order, is_active
   185→}
   186→
   187→GalleryItem { id, image_url, caption, sort_order, is_active }
   188→
   189→SiteSettings {
   190→  key (unique), value
   191→  -- e.g. site_name, logo_url, phone_dubai, phone_abudhabi,
   192→  --      email, address_dubai, address_abudhabi,
   193→  --      whatsapp_number, instagram_url, free_delivery_threshold
   194→}
   195→
   196→NewsletterSubscriber { id, email, subscribed_at, is_active }
   197→```
